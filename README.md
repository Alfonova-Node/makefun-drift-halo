Drift Halo is an original single-file arcade survival game: pilot a drifting ship inside a rotating nebula, lasso orbiting scrap with a tether beam and whip it into hunters, while a hungry gravity well pulls everything toward the core. Each ring you clear raises the danger tier with new enemy behaviors, shifting palettes and synthesized sound — all in one dependency-free TypeScript file.

## Run it

```sh
npx serve .   # or: python3 -m http.server, then open http://localhost:8000
```
